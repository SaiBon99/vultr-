# Acme

## Overview

Acme is a balanced, lightly rounded interface with responsive motion. One primary color carries every primary action; everything else is neutral. Light and dark themes are equal citizens: dark values are generated for dark backgrounds, not inverted.

Source files: `tokens.css` (all values, both themes), `tokens.json` (DTCG), `theme.css` (Tailwind v4). When a value isn't in these files, it isn't in the system: ask, don't invent.

Each color is also a 12-step scale (`--primary-1` … `--primary-12`). Steps run one way along a lightness curve and have jobs: 1–2 backgrounds, 3–5 component fills (rest, hover, pressed), 6–8 borders, 11–12 text. The brand color sits on step 9 and solid buttons use step 9 (light) / 8 (dark); use the `primary` role rather than the step. `palette.js` regenerates every scale from the seed and curve.

### Charts

Data uses its own colors, never the UI roles. `--chart-1` (green), `--chart-2` (violet), `--chart-3` (dark violet), `--chart-4` (pink), `--chart-5` (lime), `--chart-6` (dark pink) are series colors in a fixed order: use them in order and keep a series' color when filtering. Each is the mark step of a 12-step scale on the same curve as the UI, and every one reaches 3:1 on the page. Past 6 series, group the rest as `--chart-other`. `--chart-seq-1` … `--chart-seq-9` are for amounts, light to strong, from green; `--chart-div-1` … `--chart-div-9` are for values above and below a midpoint (`--chart-div-5`), from green to violet. Separate touching bars and pie slices with a 1–2px `--chart-gap`. Label series directly where you can, so color is never the only cue.

## Typography

Headings use **Geist**, text uses **Geist**, code uses **Geist Mono**. The scale ratio is 1.2, fluid between 360px and 1280px viewports (headings shrink on phones; body text never does). Line heights sit on a 4px grid (2px below 20px), and tracking tightens as size grows.

| Role | Size | Line height | Tracking | Weight | Use for |
|---|---|---|---|---|---|
| `display` | 36–48px | 56px | -0.022em | 600 | Hero and marketing headlines, once per page |
| `h1` | 27–33px | 40px | -0.022em | 600 | Page title |
| `h2` | 24–28px | 36px | -0.021em | 600 | Section title |
| `h3` | 21–23px | 32px | -0.019em | 600 | Card and group title |
| `body-lg` | 18–19px | 28px | -0.016em | 400 | Lead paragraphs and intros |
| `body` | 16px | 24px | -0.011em | 400 | Running text |
| `label` | 15px | 22px | -0.009em | 500 | Buttons, inputs, tabs, menus |
| `caption` | 12px | 20px | 0em | 400 | Metadata, helper text, timestamps |
| `code` | 15px | 24px | 0em | 400 | Inline code and code blocks |

Keep running text under 65ch wide. Use only these roles; don't set font sizes by hand.

## Layout

Spacing is a 4px grid: use `--space-*` steps only (4, 8, 12, 16, 24, 32, 48…). Controls are 36px tall (28px small, 44px large). Gutter 24px, section spacing 80px. Breakpoints: sm 640px, md 768px, lg 1024px, xl 1280px.

## Elevation & Depth

Hierarchy comes from tonal surfaces first (`bg` → `bg-subtle` → `fill`), borders second, shadows last. Shadows are tinted with the neutral hue: `--shadow-sm` for raised controls, `--shadow-md` for popovers and menus, `--shadow-lg` for dialogs. In dark mode, rely on lighter surfaces and borders; shadows are barely visible.

## Shapes

Corners are lightly rounded: sm 4px, md 8px, lg 12px, xl 16px, full for pills. Controls use `md`, cards `lg`, dialogs `xl`. **Nested corners:** inner radius = outer radius − padding, never the same radius inside and out.

## Components

Built with **shadcn/ui** (https://ui.shadcn.com). Icons: **Lucide** only, 1.5px stroke to match 400 weight text, sized to the text they sit beside (16px with body, 20px with h3). Styling: **Tailwind CSS v4**.

- **Primary button:** `primary` fill, `primary-fg` label, one per view; hover `primary-hover`, pressed `primary-active`, disabled `disabled` with `disabled-text` (exempt from contrast). Selected rows, tabs and options use `selected`.
- **Secondary button:** `fill` with `text`; hover `fill-hover`, pressed `fill-active`.
- **Input:** `bg` fill, `border` edge, `border-strong` on hover, `ring` on focus (2px, offset 2px); placeholder `text-muted`; error `danger` border with `danger-text` message.
- **Card:** `bg-subtle`, `border-subtle` edge, `lg` radius, 24px padding.
- **Badge:** `primary-subtle` with `primary-text`; status badges use `<status>-subtle` with `<status>-text`.

## Motion

Durations: fast 136ms, base 216ms, slow 336ms, spring 545ms. Enter with `--ease-out`, move on screen with `--ease-in-out`, use `--ease-spring` with `--duration-spring` for things the user drags or toggles. Animate only transform and opacity. Under `prefers-reduced-motion`, durations drop to 0.

## Do's and Don'ts

- Do use one `primary` action per view; everything else is secondary.
- Do use roles (`text`, `bg-subtle`, `border`) in components, and raw scale steps only for one-off illustration.
- Don't put `text-muted` on `primary`, or body text on any solid fill.
- Don't add colors, sizes, radii or shadows that aren't tokens. If one is missing, flag it.
- Don't mix icon sets. Lucide only.
- Don't use the same radius on nested elements.
- Do check both themes before calling a screen done.
